The TypeScript language implementation of weivel: a package that binds the C core and the C standard through koffi, a native addon that calls C from JavaScript, so that a plugin written in TypeScript or JavaScript can be hosted. It decides nothing itself: compatibility, order, reach, waiting, revocation and constraints are the core's answers, and the manifest format is the standard's; this package carries them out. It owns the modules every language implementation holds, each a subpath of the package and described in [modules/](modules/): one wrapper through which every call into the core goes, which drains the events the core queued and dispatches them in the core's order; the table from the core's handles to JavaScript objects; the timer that arms the core's next deadline on the language's own timer; each plugin's context; the host, which registers, activates and releases plugins and offers C libraries to them as host services, binding each definition from the description its library answers; the standard's defaults; the conformance driver and the benchmarks; and the optional host program, its bundler and a test helper. It is not the core, the standard or the conformance kit, and no file of it names a type of any library it binds. The package is private and unpublished. Everything runs on JavaScript's one thread, which is why the core never calls into this package and the wrapper drains instead (the core's `docs/README.md` says why the core never calls out). The one exception is a C operation whose description marks it blocking: it runs on koffi's worker thread, so the event loop stays free while it waits ([modules/descriptions.md](modules/descriptions.md)). The rules every module follows are the core's `docs/contract/`, which this tree does not restate, and the vectors that hold this package to them are the conformance kit's `docs/vectors/layer/`. How to build the package, run its tests and where its native libraries come from is answered in [building.md](building.md); how to run the host program is in [modules/program.md](modules/program.md).
